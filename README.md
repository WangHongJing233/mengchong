# 萌宠 PK (Cute Pet PK)

这是一款专门为移动端多端（微信小程序、H5等）体验设计的高颜值、Q弹可爱的应用原型。本项目基于 **Taro 4 + React 18 + Tailwind CSS** 深度重构，旨在为宠物爱好者提供一个集宠物展示、互动打榜、健康管理与社区交流于一体的平台。

## ✨ 核心功能

- 🏆 **萌宠PK对决**：基于颜值评分、日常打卡获取的萌力值和社区活跃度，与其他玩家的宠物进行趣味 PK 对决，赢取萌力值奖励。
- 📊 **排行榜系统**：展示当前所有宠物的萌力排名情况。
- 🐾 **互动与打卡**：通过“日常打卡”与“互动玩耍”功能，每天陪伴宠物成长并赚取属性分数。
- 📈 **体重健康追踪**：记录宠物的体重变化情况，并以直观的列表和卡片渲染其健康趋势。
- 💬 **萌宠社区**：展示其他宠物主人的日常动态，**支持点赞与评论交互**。
- 👤 **多宠物档案管理**：支持管理名下的多只宠物，支持在个人档案和详情页中无缝切换当前“活跃”的宠物。

## 🛠️ 技术栈

- **跨端框架**: [Taro v4.1](https://docs.taro.zone/docs/)
- **视图层**: [React 18](https://react.dev/)
- **打包工具**: [Webpack 5](https://webpack.js.org/)
- **状态管理**: [Zustand](https://github.com/pmndrs/zustand)
- **样式方案**: [Tailwind CSS v3](https://tailwindcss.com/) (借助 `weapp-tailwindcss` 插件支持小程序端)
- **语言**: TypeScript


## 🚀 快速开始

本项目使用 Node.js 与 npm 作为包管理工具进行开发。

### 环境要求

- Node.js >= 18.x
- npm 或 pnpm
- 微信开发者工具（用于小程序预览和调试）

### 安装与运行

1. 克隆项目或进入项目目录：
   ```bash
   cd workspace
   ```

2. 安装项目依赖：
   ```bash
   npm install
   ```

3. 启动微信小程序开发服务器：
   ```bash
   npm run dev:weapp
   ```

4. 启动 H5 开发服务器（浏览器预览）：
   ```bash
   npm run dev:h5
   ```

> **注意**：运行小程序开发模式后，请使用 **微信开发者工具** 打开项目根目录即可预览和调试。

### 构建与部署

构建微信小程序生产版本文件：
```bash
npm run build:weapp
```
构建产物将会生成在 `dist` 目录下。

## 🎨 设计与交互亮点

1. **移动端优先**：深度契合微信小程序的设计规范，采用浅灰背景 `#f7f8fa` 搭配大圆角 `2rem` 白底卡片，视觉层级清晰。
2. **细腻的交互动画**：通过原生 CSS `@keyframes` 和 Tailwind 类名实现了首页元素的微动效（如呼吸灯、跳动效果）、按钮和卡片的点击缩放反馈（`active:scale-95`）。
3. **色彩搭配**：以“治愈系”为主题的温暖橙黄色（Orange）与薄荷绿辅助色相搭配，界面明亮活泼。
4. **组件解耦与状态共享**：使用 Zustand 进行全局状态管理，在“我的”和“档案详情”页面切换宠物后，首页展示内容会自动同步响应。

---
*本项目当前为纯前端 Mock 数据驱动的版本，API 层与后台通信预留在 `store/index.ts` 中，以便于未来无缝接入真实的后端服务。*
