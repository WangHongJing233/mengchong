# 全局 UI 视觉重构 Spec

## Why
当前的页面样式虽然在布局上解决了重叠问题，但在美感上仍然显得平庸，缺乏个性化和高级感。用户指出“社区页面毫无美感”，且希望所有页面的样式都能得到精美化。我们需要运用 `frontend-design` 技能，确立一个**「Playful & Premium (活泼且高级的宠物主题)」**的美学方向，彻底升级全站的视觉体验，消除“通用AI生成感”。

## What Changes
- **Aesthetic Direction (美学方向)**：
  - **Tone**: Playful & Soft (活泼、柔软、充满治愈感)。
  - **Color**: 以温暖明亮的橙黄色 (`#ff8f0a`) 为主色调，辅以柔软的背景色 (`#fffcf8` 或 `#fdfbf7`)，大面积留白。
  - **Shapes**: 使用超大圆角（`32px` 或 `full`），消除所有锐利的直角，打造“Q弹”的视觉感受。
  - **Shadows**: 使用带有色彩倾向的柔和阴影，取代生硬的黑灰色阴影。
  - **Typography**: 标题加粗加大，增加字重对比，利用层级关系引导视线。

- **页面重构细节**：
  1. **社区页面 (`community/index.tsx`)**：
     - 重构帖子卡片：去掉生硬的边框，采用无边框+大圆角+超柔和彩色阴影的设计。
     - 图片展示：采用非对称或更有趣的圆角设计，或者赋予图片轻微的悬浮感。
     - 评论与点赞区：使用带有高斯模糊效果或极浅底色的微卡片承载交互按钮，让点赞和评论数字更具设计感。
     - 顶部 Header：增加毛玻璃效果（Backdrop Blur），让滚动时的过渡更顺滑高级。
  2. **首页 (`index/index.tsx`)**：
     - 强化宠物展示区的“舞台感”，使用渐变光晕和粒子动画效果作为背景。
     - 底部操作按钮升级为具有立体感（Neumorphism 或拟物化微光效）的图标按钮。
  3. **个人中心 (`profile/index.tsx`)**：
     - 顶部背景使用柔和的不规则渐变或曲线分割。
     - 宠物列表采用卡片堆叠或更具张力的滑动交互。
  4. **健康与详情页 (`health`, `pet-detail`)**：
     - 统一为同套美学风格，数据展示区域采用清新的卡片排版。
  5. **TabBar 图标优化**：
     - 重新生成带有柔和渐变色或精美图案的 TabBar 图片，替代目前简陋的色块。

## Impact
- Affected specs: 全局视觉系统 (Global UI Design System)
- Affected code:
  - `src/app.scss` (添加全局动画与渐变类)
  - `tailwind.config.js` (扩展阴影和圆角)
  - `src/pages/**/*.tsx` (重构所有页面的 JSX 结构与类名)
  - `src/assets/tabbar/*.png` (重新生成更精美的图标)

## ADDED Requirements
### Requirement: 沉浸式高级视觉体验
系统应当提供极具辨识度的宠物主题 UI。
#### Scenario: 用户浏览任何页面
- **WHEN** 用户打开首页、社区或个人中心
- **THEN** 看到的是具有统一个性化美学（大圆角、彩色柔和阴影、呼吸动画）的高级界面，交互按钮有明显的触态反馈，彻底告别粗糙感。
